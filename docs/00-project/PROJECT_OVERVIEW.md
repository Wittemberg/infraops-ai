# Project Overview — InfraOps AI

## Missão

Permitir que uma equipe de infraestrutura saiba rapidamente **o que precisa de atenção agora**, compreenda o motivo e, quando autorizada, execute ações seguras e auditáveis.

## Público inicial

- MSPs;
- empresas de suporte;
- equipes de infraestrutura;
- provedores que administram múltiplos clientes;
- ambientes com Linux, Proxmox VE e Virtualizor.

## Capacidades centrais

1. Monitorar nodes e workloads.
2. Monitorar e governar backups.
3. Antecipar pressão de storage e incidentes.
4. Consolidar alertas e histórico.
5. Oferecer IA contextual em linguagem natural.
6. Executar Actions controladas para usuários autorizados.
7. Oferecer portal read-only para clientes finais.
8. Manter rastreabilidade completa.

## Princípio de produto

> O dashboard mostra exceções; a IA explica contexto; Actions executam mudanças governadas.
